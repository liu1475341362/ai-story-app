# StarWhisper — AI Interactive Story Chat

> **StarWhisper (星语)** is an Android app for immersive, AI-driven interactive storytelling.
> Users browse a library of fictional story scenarios, chat in real time with AI-powered
> characters, and shape the direction of each story through their own conversation choices.

- **Package name:** `com.lbn.story`
- **Current version:** 2.5.0
- **Developer:** Individual developer (solo project)
- **Platform:** Android 11+ (minSdk 30, targetSdk 36)

---

## 📋 About This App

StarWhisper combines a story library with real-time AI chat:

1. **Story library ("Discover")** — Users browse story cards organized by category
   (e.g. urban, historical, campus). Each story defines a setting, characters, and a
   narrative goal.
2. **Interactive chat** — Users enter a story and chat with its AI character. Replies are
   generated by an AI backend and streamed token-by-token over Server-Sent Events (SSE).
3. **Scene progression** — A small on-device AI model (LiteRT/TFLite) scores how well each
   user message advances the current scene's goal. When enough progress accumulates, the
   story moves to the next scene, creating a game-like narrative flow.
4. **Conversations tab** — Recent chats, unread badges, pinning, and deletion.
5. **System integration** — Bubble notifications (Android 11+), MessagingStyle notifications
   with quick reply, Deep Links, and Direct Share.

### Target audience

The app targets general entertainment users who enjoy interactive fiction, role-playing
stories, and AI conversation. All characters are fictional. All story content is
pre-authored or AI-generated fiction; the app contains **no user-to-user communication and
no user-generated content shared between users**.

## ✨ Key Features

- ✅ Real-time AI chat with SSE streaming responses (with automatic retry and graceful
  fallback to non-streaming mode)
- ✅ Story library with category filters, dynamically synced from our backend
- ✅ On-device scene-progress inference (LiteRT + TinyBERT), no user text leaves the device
  for this scoring step

- ✅ Notification settings, privacy settings, and security settings
- ✅ Material3 theming with light/dark and dynamic color support
- ✅ Bubble notifications, quick reply from notification shade, Deep Link, Direct Share

## 🏗️ Technical Overview

| Aspect | Details |
|--------|---------|
| **Languages** | Kotlin (primary), Java (some modules) |
| **Architecture** | MVVM + Repository + DTO adapter layer |
| **UI** | Jetpack Compose + Material3 (conversation list, filters); XML Views (chat screen) |
| **State** | ViewModel + StateFlow / LiveData |
| **Networking** | Retrofit + OkHttp; SSE streaming via OkHttp event source |
| **Local storage** | Room (5 tables: messages, story cache, conversation meta, scenes, characters), MMKV for preferences |
| **On-device AI** | LiteRT (Google AI Edge) running a TinyBERT model for scene-progress scoring, GPU with CPU fallback |
| **Images** | Glide with network-first + local-file fallback |
| **Performance** | Baseline Profiles for startup optimization |

### High-level module layout

```
app/src/main/java/com/xiaoshuohui/story/
├── ui/            # Screens: auth, chat, conversation list, discover, mine,
│                  # settings, bubble, voice, theme
├── data/          # Repositories, chat session manager, Room DB, DTO adapters
├── network/       # Retrofit client, API services, SSE streaming layer
├── agent/         # On-device scene inference engine (LiteRT) + tokenizer
└── util/          # Utilities
```

## 🔐 Permissions Used

The app requests only the minimum permissions needed for its core functionality:

| Permission | Why it is needed |
|------------|------------------|
| `INTERNET` | To fetch story content, stream AI chat replies, and handle account APIs |
| `ACCESS_NETWORK_STATE` | To detect connectivity and choose streaming vs. offline fallback behavior |
| `POST_NOTIFICATIONS` (Android 13+) | To notify users of new AI replies and offer quick reply from the notification shade |

The app does **not** request location, contacts, camera, microphone, storage, phone, or
any other sensitive permissions.

## 🛡️ Data & Privacy

- **Data collected:** account email (for registration/login), user profile (nickname,
  avatar choice), and chat history with AI characters.
- **Data storage:** chat history and story cache are stored locally on the device in a
  private Room database. Account data resides on the developer's backend
  (`https://www.lbnself.xyz/`) over HTTPS.
- **On-device inference:** scene-progress scoring runs entirely on the device; the user's
  message text is not sent to any additional service for that purpose.
- **No third-party sharing:** user data is not sold or shared with third parties for
  advertising or other purposes.
- **Data deletion:** users can delete their conversations at any time inside the app
  (long-press a conversation → Delete). Users can fully delete their account in-app via
  **Settings → Account → Account Deletion**, which removes account data from the backend.
  Users may also contact the developer at the support email below for deletion requests.

These behaviors are reflected consistently in the app's Play Console Data Safety form.

## 🧪 Testing Instructions for Reviewers

To help the review team verify core functionality:

1. **Install & launch** — the app shows the login screen on first launch. Register a new
   account with any email address (email verification code is delivered by the backend),
   or use the demo account provided in the Play Console review notes.
2. **Story library** — open the middle tab ("Discover") and wait for story cards to load
   from the backend.
3. **Chat flow** — tap any story card → send a message → verify the AI reply streams in
   token-by-token. Messages persist across app restarts (offline cache).
4. **Conversations tab** — verify unread badge, pinning (long-press → Pin), and deletion
   (long-press → Delete).
5. **Account deletion** — Settings → Account → Account Deletion: verify the flow completes
   in-app without requiring external contact.
6. **Notifications** — allow notification permission when prompted; new AI replies while
   the app is in background produce MessagingStyle notifications with quick reply.

If any step fails during review, please contact the developer via the support email —
issues are typically addressed within 24 hours.
